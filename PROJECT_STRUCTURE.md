
# Portfolio Project Structure

This repository contains my personal portfolio website.

## Files and Folders

```text
bibijainabportfolio/
│
├── index.html
├── style.css
├── script.js
├── README.md
├── PROJECT_STRUCTURE.md
├── .gitignore
│
└── .vscode/
    └── settings.json
```

## File Description

- `index.html` – Main structure of the portfolio website.
- `style.css` – Styling and responsive design.
- `script.js` – Website interactions and functionality.
- `README.md` – Project introduction and documentation.
- `PROJECT_STRUCTURE.md` – Folder and file documentation.
- `.gitignore` – Files excluded from Git tracking.
- `.vscode/` – Local Visual Studio Code settings.
